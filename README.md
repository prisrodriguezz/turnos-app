# Aura Estética - Sistema de Gestión de Turnos

Aplicación web para la gestión y reserva de turnos de un centro de estética.

El objetivo del proyecto es digitalizar la administración de citas, permitiendo a los clientes solicitar turnos de forma sencilla y al negocio gestionar servicios, horarios y reservas desde un panel administrativo.

## 🚀 Funcionalidades

### Cliente
- Solicitud de turnos online.
- Selección de servicio, profesional y fecha disponible.
- Validación de horarios disponibles.
- Confirmación de reserva.

### Administración
- Gestión de turnos.
- Administración de servicios y profesionales.
- Seguimiento del estado de las reservas.

## 🛠️ Tecnologías utilizadas

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core

### Base de datos
- SQL Server

## 📌 Estado del proyecto

🚧 En desarrollo.

Actualmente se encuentra en etapa de construcción del sistema de reservas y la integración entre frontend, backend y base de datos.

## 🎯 Objetivo

Crear una solución simple, escalable y fácil de usar para pequeños negocios que necesitan administrar sus turnos y mejorar la experiencia de sus clientes.
